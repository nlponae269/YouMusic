# Сюда загружай музыку

**Add file → Upload files**, выбери треки, нажми **Commit changes**. Через 1–2 минуты они появятся на сайте.

- Форматы: MP3, M4A, OGG, OPUS, FLAC, WAV. Через браузер GitHub принимает файлы до 25 МБ.
- Название, исполнитель, альбом и обложка берутся из тегов файла.
- Если тегов нет, назови файл `Исполнитель - Название.mp3`.
- **Обложка:** картинка с тем же именем рядом (`Исполнитель - Название.jpg`) или `cover.jpg` на всю папку.
- **Текст песни:** файл с тем же именем и расширением `.lrc` (с таймкодами, строки подсвечиваются в такт) или `.txt`.

Пример LRC:

```
[00:12.40] Город гасит окна по одному
[00:17.85] Мы ловим ритм на пустом шоссе
```

Пока здесь нет ни одного трека, на сайте играют демо-треки.
