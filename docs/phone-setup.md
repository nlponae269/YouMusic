# Запуск YouMusic только с телефона

Как это устроено:

- **Yandex Cloud** держит сервер, базу и музыку.
- **GitHub Pages** держит сам сайт: `https://nlponae269.github.io/YouMusic/`.
- **GitHub Actions** всё собирает и выкатывает по одной кнопке. Компьютер не нужен.

Всё делается в обычном браузере телефона. Если какого-то пункта меню не видно, включи в браузере «Версия для ПК».

---

## Часть 1. Yandex Cloud

Открой https://console.yandex.cloud и войди через Яндекс ID.

### 1. Платёжный аккаунт
При первом входе консоль попросит создать платёжный аккаунт и привязать карту. Новым пользователям дают стартовый грант. Облако и каталог `default` создадутся сами.

### 2. ID каталога
Открой каталог `default`. Под его названием есть ID вида `b1g…`. Скопируй его и сохрани в заметки: это **YC_FOLDER_ID**.

### 3. Сервисный аккаунт (от его имени GitHub будет управлять облаком)
1. Меню ☰ → **Identity and Access Management** → **Сервисные аккаунты** → **Создать сервисный аккаунт**.
2. Имя: `youmusic-sa`.
3. Добавь две роли: `editor` и `serverless.containers.admin`.
4. Нажми **Создать**.

### 4. Ключи сервисного аккаунта
Открой `youmusic-sa`. Сверху будет кнопка **Создать новый ключ**.

**а) Авторизованный ключ**
1. **Создать новый ключ** → **Создать авторизованный ключ** → алгоритм `RSA_2048` → **Создать**.
2. Нажми **Скачать файл с ключами**, скачается `authorized_key.json`.
3. Открой файл (например, через «Файлы» → открыть как текст), выдели **весь** текст от `{` до `}` и скопируй.
4. Это **YC_SA_KEY**.

**б) Статический ключ доступа (для хранилища музыки)**
1. **Создать новый ключ** → **Создать статический ключ доступа** → **Создать**.
2. Консоль покажет два значения. ⚠️ Они показываются **один раз**, сразу сохрани оба:
   - «Идентификатор ключа» — это **S3_ACCESS_KEY_ID**;
   - «Ваш секретный ключ» — это **S3_SECRET_ACCESS_KEY**.

### 5. База данных PostgreSQL
Меню ☰ → **Managed Service for PostgreSQL** → **Создать кластер**. Заполни:

| Поле | Значение |
|---|---|
| Имя кластера | `youmusic-pg` (именно так) |
| Окружение | `PRODUCTION` |
| Версия | `16` |
| Класс хоста | самый дешёвый: вкладка с **частичной долей vCPU** (burstable) |
| Хранилище | `network-hdd`, 10 ГБ |
| Имя БД | `youmusic` |
| Имя пользователя | `youmusic` |
| Пароль | придумай пароль только из **латинских букв и цифр**, минимум 8 символов. Это **DB_PASSWORD** |
| Хосты | нажми ✏️ у хоста и включи **Публичный доступ** |

Нажми **Создать кластер** и подожди, пока статус станет **Alive** (около 10 минут).

Бакет для музыки, реестр образов и контейнер создавать не нужно: их сделает GitHub на первом запуске.

## Часть 2. GitHub

Заходи на https://github.com/nlponae269/YouMusic через браузер. В приложении GitHub нет нужных настроек.

### 1. Сделать репозиторий публичным
На бесплатном тарифе GitHub Pages работает только с публичными репозиториями. Пароли и ключи никто не увидит: они хранятся в секретах, а не в коде.

**Settings** → прокрути до **Danger Zone** → **Change visibility** → **Public**.

### 2. Включить Pages
**Settings** → **Pages** → **Build and deployment** → **Source**: выбери **GitHub Actions**.

### 3. Добавить секреты
**Settings** → **Secrets and variables** → **Actions** → **New repository secret**. Добавь шесть штук; имя пиши точно как в таблице:

| Name | Что вставить |
|---|---|
| `YC_SA_KEY` | весь текст из `authorized_key.json` |
| `YC_FOLDER_ID` | ID каталога `b1g…` |
| `DB_PASSWORD` | пароль от базы |
| `S3_ACCESS_KEY_ID` | идентификатор статического ключа |
| `S3_SECRET_ACCESS_KEY` | секретный ключ статического ключа |
| `ADMIN_TOKEN` | придумай пароль для админки сайта |

### 4. Запустить деплой
1. Вкладка **Actions** → слева **Deploy** → **Run workflow**.
2. Поставь галочку **«Залить демо-треки»**, чтобы сразу было что послушать.
3. Нажми **Run workflow**.

Первый запуск идёт примерно 5 минут. Когда появятся две зелёные галочки, всё готово.

### 5. Пользоваться
- Сайт: **https://nlponae269.github.io/YouMusic/**
- Админка (заливать свою музыку): **https://nlponae269.github.io/YouMusic/admin.html**, вход по `ADMIN_TOKEN`.
- Чтобы сайт открывался как приложение: в браузере меню → **«Добавить на главный экран»**.

Каждый новый запуск **Deploy** выкатывает свежую версию кода. Демо-треки повторно не добавляются, если в каталоге уже есть музыка.

## Если что-то не так

**Красный крестик в Actions.** Нажми на упавший шаг, там будет текст ошибки:
- `Не задан секрет …` — проверь имя секрета, оно должно совпадать буква в букву.
- `Кластер PostgreSQL «youmusic-pg» не найден` — проверь имя кластера или подожди статуса Alive.
- `Permission denied` или `403` — проверь роли сервисного аккаунта (шаг 1.3).

**Сайт открывается, но вместо музыки ошибка.**
1. Открой адрес сервера, допиши к нему `/api/health`. Адрес написан в Actions → последний запуск → **Summary** → «Сервер: https://….containers.yandexcloud.net».
2. Если там ошибка подключения к базе, у кластера закрыт порт. В консоли Яндекса: ☰ → **Virtual Private Cloud** → **Группы безопасности** → группа `default…` → **Изменить** → добавь **входящее** правило: порт `6432`, протокол `TCP`, источник `CIDR` `0.0.0.0/0`.
3. Потом снова запусти **Deploy**.

**В админке файлы не загружаются.** Запусти **Deploy** ещё раз: он заново настроит доступ к хранилищу.

## Сколько это стоит

- Хранилище и контейнер — копейки при небольшой нагрузке: оплата только за реально использованное.
- Основной расход — кластер PostgreSQL: он тарифицируется, пока запущен, даже если сайтом никто не пользуется.
- Текущие цены смотри в калькуляторе на yandex.cloud.
- Если не пользуешься, кластер можно **остановить**: страница кластера → **⋯** → **Остановить**.
