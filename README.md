# YouMusic

Бесплатный музыкальный стриминг: сайт на **GitHub Pages**, аккаунты и музыка в **Supabase** (бесплатный тариф, без карты).
Любой может зарегистрироваться и загрузить трек. Перед публикацией нейросеть вырезает из трека мат и упоминания наркотиков, а на их месте остаётся бит.

## Как работает цензура

1. Пользователь загружает трек. Он попадает в закрытую очередь, и на сайте его пока не видно.
2. Каждые 10 минут GitHub Actions забирает новые загрузки (это бесплатно).
3. **Demucs** (нейросеть) разделяет трек на голос и бит.
4. **Whisper** (нейросеть) расшифровывает голос пословно, с точным временем каждого слова.
5. На месте запрещённых слов голос убирается, бит продолжает играть. Если к треку приложен текст в формате LRC и в строке есть мат, который нейросеть не расслышала, голос убирается на всю эту строку.
6. В названии и тексте песни такие слова заменяются звёздочками.
7. Публикуется только отцензуренная версия, оригинал удаляется.

Словарь лежит в [`processor/words.py`](processor/words.py): мат и оскорбления, наркотики и зависимость, суицид (в том числе фразы вроде «убью себя»). Запрещённые слова прячутся и в названиях. Когда словарь меняется, уже опубликованные треки перепроверяются автоматически.

## Генератор песен

Страница **«Создать песню»**: пользователь выбирает жанр, настроение, голос, язык и длину, пишет текст, и нейросеть **[ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5)** (MIT) сочиняет музыку и поёт. Всё бесплатно: генерация идёт на процессоре в GitHub Actions, примерно 2–3 минуты на каждые 30 секунд песни.

- Запрещённые слова вырезаются из текста и описания **до** генерации, чтобы модель их не спела.
- Готовая песня проходит ту же проверку, что и загрузки (Demucs + Whisper), и только потом публикуется.
- Песни нейросети помечены альбомом «Сгенерировано нейросетью».

## SoundCloud

В профиле есть поле **«Добавить из SoundCloud»**: вставляешь ссылку на трек, и через несколько минут он появляется на сайте. Название, артист и обложка берутся из официального oEmbed SoundCloud, сам звук не копируется. Трек играет у нас через **официальный плеер SoundCloud**, наши кнопки им управляют.

- Такие треки помечены значком «SoundCloud».
- Скачать их нельзя.
- Нашу цензуру они не проходят: звук идёт с серверов SoundCloud, и изменить его мы не можем.
- На телефоне SoundCloud иногда просит нажать ▶ внутри своего плеера: так работают ограничения браузеров на автозапуск.

ВК так подключить нельзя: у ВК нет ни открытого API для музыки, ни плеера для встраивания на чужие сайты.

## Тексты песен

Ничего добавлять не нужно. Обработчик сам ищет текст в открытой базе [LRCLIB](https://lrclib.net), с таймкодами, чтобы строки подсвечивались в такт. Если там текста нет, его записывает нейросеть Whisper по самому треку. Уже опубликованным трекам тексты подтягиваются тоже. Мат в текстах заменяется звёздочками.

## Что ещё делается само

- Загрузки с ошибкой удаляются через 3 дня.
- Файлы удалённых треков стираются из хранилища.
- Если обработка зависла, трек возвращается в очередь.

⚠️ Нейросеть ошибается. Она может не расслышать слово в быстром рэпе или под громким битом. Это сильно снижает риск, но не даёт стопроцентной гарантии.

## Настройка с телефона

Всё делается в браузере. Если пункта меню не видно, включи «Версия для ПК».

### 1. Supabase (база, аккаунты, хранилище)
1. Открой **https://supabase.com** → **Start your project** → **Continue with GitHub**.
2. **New project**:
   - Name: `youmusic`;
   - Database Password: нажми **Generate a password** и сохрани пароль;
   - Region: ближайший (например, Frankfurt);
   - нажми **Create new project** и подожди пару минут.
3. **SQL Editor** → **New query**. Открой на GitHub файл [`supabase/schema.sql`](supabase/schema.sql) → кнопка **Raw** → выдели всё и скопируй → вставь в редактор → **Run**. Должно появиться `Success`.
4. **Authentication** → **Sign In / Providers** → **Email** → выключи **Confirm email** → **Save**. Иначе каждому придётся подтверждать почту, а бесплатный тариф отправляет всего несколько писем в час.
5. **Authentication** → **URL Configuration** → **Site URL**: `https://nlponae269.github.io/YouMusic/` → **Save**.
6. Включи в браузере **«Версия для ПК»**: в мобильном виде Supabase прячет кнопки копирования. Открой **Project Settings** (шестерёнка) → **API Keys**. Скопируй и сохрани в заметки два ключа:
   - **Publishable key** (`sb_publishable_…`) — публичный ключ; в старых проектах он называется `anon` `public`;
   - **Secret key** (`sb_secret_…`): нажми 👁 или **Reveal**, потом копировать. В старых проектах — `service_role`. **Никому не показывай.**

   Копировать — иконка с двумя квадратиками справа от ключа.
7. Нажми **Connect** вверху страницы проекта → скопируй **Project URL** (вида `https://xxxx.supabase.co`).

### 2. GitHub
**Settings** → **Secrets and variables** → **Actions**.
- Вкладка **Variables** → **New repository variable**, добавь две:
  - `SUPABASE_URL` — Project URL;
  - `SUPABASE_ANON_KEY` — Publishable key (или `anon`).
- Вкладка **Secrets** → **New repository secret**, добавь одну:
  - `SUPABASE_SERVICE_KEY` — Secret key (или `service_role`).

Затем **Actions** → **Deploy** → **Run workflow**. Через минуту сайт обновится.

### 3. Администратор
Ничего делать не нужно. Администратором автоматически становится аккаунт владельца (его почта задана в [`processor/admins.py`](processor/admins.py) в виде хэша). У администратора в профиле есть раздел **«Все треки»**: там можно удалить любой трек.

## Что где хранится

| Что | Где |
|---|---|
| Сайт | GitHub Pages |
| Аккаунты, список треков | Supabase (база) |
| Музыка и обложки | Supabase Storage. Бесплатно 1 ГБ: это примерно 250 треков в MP3 128 кбит/с, загрузка одного файла до 50 МБ |
| Лайки, плейлисты | Браузер на устройстве |
| Цензура | GitHub Actions, запуск каждые 10 минут |

## Если что-то не так

- **Трек долго «В очереди».** Открой **Actions** → **Process uploads** и посмотри последний запуск. Его можно запустить вручную: **Run workflow**. Первый запуск дольше остальных: скачиваются нейросети, около 2 ГБ.
- **«Ошибка» у трека.** Причина написана рядом со статусом. Чаще всего это битый или неподдерживаемый файл.
- **Сайт пишет «не подключён».** Проверь переменные `SUPABASE_URL` и `SUPABASE_ANON_KEY`, затем перезапусти **Deploy**.
- **Supabase «уснул».** Бесплатные проекты без активности приостанавливаются. Открой проект на supabase.com и нажми **Restore**.

## Важно

Сайт публичный. Если пользователи загружают чужую музыку без разрешения, правообладатель может потребовать её удалить. При загрузке каждый подтверждает, что у него есть права на трек; нарушения удаляй через раздел «Все треки».
