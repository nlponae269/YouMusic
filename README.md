# YouMusic

Бесплатный музыкальный стриминг на **GitHub Pages**: без серверов, без баз данных, без оплаты.
Музыка лежит прямо в репозитории в папке `music/`, сайт собирается сам.

## Что умеет

- Плеер с большой обложкой; фон и акцент перекрашиваются под каждый трек.
- Волна-прогресс (перемотка тапом), shuffle, повтор, громкость, скачивание трека.
- Подборки «Моя волна», «Новинки», «На повторе», «Любимое»; обновляются раз в час.
- Текст песни: обычный или LRC, строки подсвечиваются в такт.
- Лайки и плейлисты. Хранятся в браузере на устройстве.
- Поиск и голосовой поиск.
- Управление с экрана блокировки; можно установить на главный экран как приложение.

## Запуск только с телефона

Всё делается в браузере (не в приложении GitHub). Если пункта меню не видно, включи в браузере «Версия для ПК».

### 1. Сделать репозиторий публичным
На бесплатном тарифе GitHub Pages работает только с публичными репозиториями.

**Settings** → внизу **Danger Zone** → **Change visibility** → **Public**.

### 2. Включить Pages
**Settings** → **Pages** → **Build and deployment** → **Source**: **GitHub Actions**.

### 3. Запустить сборку
**Actions** → слева **Deploy** → **Run workflow** → **Run workflow**.

Через 1–2 минуты появятся зелёные галочки. Сайт будет здесь: **https://nlponae269.github.io/YouMusic/**

Пока своей музыки нет, на сайте играют демо-треки.

### 4. Залить свою музыку
1. Открой папку **`music`** в репозитории.
2. Нажми **Add file** → **Upload files** и выбери треки с телефона.
3. Внизу нажми **Commit changes**.

Сайт пересоберётся сам, новые треки появятся через 1–2 минуты. Подробности (обложки, тексты, имена файлов) — в [music/README.md](music/README.md).

### 5. Поставить как приложение
Открой сайт в браузере → меню → **«Добавить на главный экран»**.

## Ограничения GitHub

- Через браузер можно загрузить файл до **25 МБ**. Обычный MP3 весит 3–10 МБ, так что хватает.
- Весь сайт должен укладываться примерно в **1 ГБ**. Это около 150–250 треков в MP3. Чтобы влезло больше, пережимай треки в 128 кбит/с.
- Лайки и плейлисты живут в браузере. В другом браузере или на другом телефоне их не будет.
- Репозиторий публичный: все файлы в нём может скачать кто угодно. Чужие треки без лицензии там могут удалить по жалобе правообладателя, а аккаунт — заблокировать. Безопаснее заливать свою музыку или треки со свободной лицензией.

## Для разработчиков

Сборка нужна Node.js 20+ и ffmpeg:

```bash
npm run preview   # собрать в _site/ и открыть на http://localhost:8080
```

`scripts/build-site.js` читает теги через `ffprobe`, достаёт обложки и считает волну через `ffmpeg`, затем складывает `catalog.json` и файлы в `_site/media/`.
