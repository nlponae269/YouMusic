# supMUSIC

Музыкальный стриминг в духе Яндекс Музыки: «Моя волна», поиск, лайки, плейлисты, плеер с очередью и **текстом песни с подсветкой строк**. Сайт на **GitHub Pages**, аккаунты, база и файлы в **Supabase** (бесплатный тариф), нейросети работают в **GitHub Actions** бесплатно.

Любой может зарегистрироваться, загрузить трек или попросить нейросеть сочинить песню. Перед публикацией нейросеть вырезает из трека мат, наркотики и суицид, а на их месте остаётся бит.

## Нейросети

| Задача | Модель | Где работает |
|---|---|---|
| Разделить трек на голос и бит | **[Demucs](https://github.com/facebookresearch/demucs) `htdemucs`** (Meta, MIT) | Actions, процессор |
| Расшифровать вокал пословно, с точным временем | **[Whisper `medium`](https://github.com/openai/whisper)** через [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (OpenAI, MIT) | Actions, процессор |
| Сочинить песню и спеть текст | **[ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5) turbo** (MIT) | Actions, процессор |
| Тексты песен с таймкодами | открытая база **[LRCLIB](https://lrclib.net)** | запрос из обработчика |

## Как работает цензура

1. Пользователь загружает трек. Он попадает в закрытую очередь (`sup-incoming`), на сайте его пока не видно, а в «Коллекции» у автора он помечен «На проверке».
2. Каждые 10 минут GitHub Actions забирает новые загрузки (workflow [`process.yml`](.github/workflows/process.yml)).
3. **Demucs** разделяет трек на голос и бит.
4. **Whisper** расшифровывает голос пословно, с точным временем каждого слова.
5. На месте запрещённых слов голос убирается, бит продолжает играть. Если приложен текст в формате LRC и в строке есть запрещённое слово, которое нейросеть не расслышала, голос убирается на всю строку.
6. В названии и тексте песни такие слова заменяются звёздочками.
7. Публикуется только отцензуренная версия, оригинал удаляется.

Словарь лежит в [`processor/words.py`](processor/words.py): мат и оскорбления, наркотики и зависимость, суицид (в том числе фразы вроде «убью себя»). Когда словарь меняется, уже опубликованные треки перепроверяются автоматически.

## Текст песни, как в Яндекс Музыке

Полноэкранный плеер (тап по мини-плееру или по обложке внизу) показывает текст:

- текущая строка подсвечена, остальные бледнее и размытее по мере удаления, список сам прокручивается;
- тап по строке перематывает на неё;
- в проигрышах и во вступлении пульсируют три точки;
- если у текста нет таймкодов, он показывается целиком без подсветки.

Откуда берётся текст: свой, если автор вставил при загрузке; иначе из **LRCLIB** (с таймкодами); если там нет, его с таймкодами записывает **Whisper**. У песен нейросети текст тоже записывает Whisper, чтобы подсветка совпадала со звуком.

## Генератор песен

Страница **«Создать песню»**: жанр, настроение, голос, язык, длина и текст, а **ACE-Step 1.5** сочиняет музыку и поёт. Всё бесплатно: генерация идёт на процессоре в GitHub Actions, примерно 2–3 минуты на каждые 30 секунд песни.

- Запрещённые слова вырезаются из текста и описания **до** генерации, чтобы модель их не спела.
- Готовая песня проходит ту же проверку, что и загрузки (Demucs + Whisper), и только потом публикуется.
- Песни нейросети помечены значком «ИИ».

## Запуск

1. В Supabase откройте **SQL Editor** и выполните [`supabase/schema.sql`](supabase/schema.sql): таблицы `sup_*`, права и хранилище. Повторный запуск безопасен.
2. В репозитории, в **Settings → Secrets and variables → Actions → Secrets**, добавьте:
   - `SUPABASE_URL` и `SUPABASE_ANON_KEY` (Project Settings → API): для сайта;
   - `SUPABASE_SERVICE_KEY` (там же, ключ **service_role**): для обработчика нейросетей. Он нужен, чтобы публиковать проверенные треки. Не вставляйте его в код и не показывайте никому.
3. **Settings → Pages → Source: GitHub Actions.** Сайт публикуется при каждом пуше в основную ветку, секреты подставляются в `public/config.js` во время сборки.
4. Нейросети запускаются сами каждые 10 минут по расписанию, вручную: Actions → Process uploads → Run workflow. Первый запуск дольше, потому что скачивает модели, потом они берутся из кэша.
5. В Supabase → Authentication можно отключить подтверждение почты, если не нужно письмо при регистрации.

Локально: впишите URL и ключ в `public/config.js` и откройте `public/` любым статическим сервером (`python3 -m http.server -d public`). Файл с ключами не коммитьте.
